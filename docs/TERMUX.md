# Termux

This project can be hosted from Android using Termux.

## Install Requirements

- Install Termux from a trusted source.
- Install Node.js inside Termux.

## Run

```bash
cd /path/to/connect/server
npm install
npm start
```

## Notes

- Termux devices can expose a local hotspot or join the same Wi-Fi network as the client devices.
- The server prints the local IP address and QR code in the terminal.
- Keep the Termux session alive while other devices use the app.
